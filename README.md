💻 LINQ-Kurs mit C#
📌 Projektbeschreibung

Dieses Repository enthält Übungen und Beispiele aus einem Kurs über Language Integrated Query (LINQ) in C#.

Ziel des Projekts ist es, die Grundlagen von LINQ zu verstehen und zu lernen, wie Daten in C# effizient abgefragt, gefiltert, sortiert und verarbeitet werden können.

🎯 Lernziele
Die Grundlagen von LINQ verstehen
Daten mit LINQ abfragen und filtern
Daten sortieren und gruppieren
Mit Collections und Listen arbeiten
LINQ-Abfragen mit C# implementieren
Die Lesbarkeit und Effizienz des Codes verbessern
🛠️ Verwendete Technologien
C#
.NET
LINQ
Visual Studio
📚 Behandelte Themen
LINQ-Grundlagen
Query Syntax und Method Syntax
Where() – Filtern von Daten
Select() – Auswählen und Transformieren von Daten
OrderBy() und OrderByDescending() – Sortieren von Daten
GroupBy() – Gruppieren von Daten
First(), FirstOrDefault(), Single() und SingleOrDefault()
Any() und All() – Überprüfen von Bedingungen
Count(), Sum(), Min() und Max()
Arbeiten mit Listen und Collections
